# LinkVault v1.0.0

The first GitHub release of LinkVault, a local-first reading library for links shared in chats.

## Highlights

- One reading list across chats, with duplicate URLs combined.
- Reading states, compact pagination, reports, topic and site filters.
- Custom topics, visible chat controls, safe chat deletion, and JSON backup/restore.
- Markdown export for Obsidian or your preferred external AI workflow.
- Light and dark editorial themes, with no analytics, account, or hosted database.

## Install

Download and extract `linkvault-chromium-1.0.0.zip`. In Chrome or another Chromium browser, open the extensions page, enable Developer mode, choose **Load unpacked**, and select the extracted folder.

This is not a Chrome Web Store release. Firefox is not supported yet.

## Important

LinkVault stores its library locally in the browser profile. Download JSON backups before changing browsers, clearing browser data, or uninstalling the extension.

The optional LinkedIn live-collection modes can violate LinkedIn rules and can lead to account restrictions. They are not promoted as safe or complete. HTML and TXT import do not interact with LinkedIn.
