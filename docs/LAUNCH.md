## Short description

For the articles your friends send and you definitely, absolutely plan to read. A local reading list with chat collections, reading states, and Markdown export.

## LinkedIn draft

Your friend sends you an article.

"Looks good, I'll read it later."

Then they send another one. And another one.

Now the chat is a reading list, except you can't find anything 😂

That was me. My friends and I share a lot of useful links, but finding them again was a pain. So I saved the chat HTML and wrote a script to pull the links out.

Then I turned it into a browser extension: LinkVault.

It puts the links in one place, groups them by chat and topic, and lets me track what I've read. It also exports Markdown for Obsidian. The library stays in the browser, with backups I can move to another device.

Will I finally read them all? Let's not make promises.
