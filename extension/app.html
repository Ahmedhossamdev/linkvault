Export & backup

Markdown exports all pages of the current filtered list, read or unread. JSON backs up the entire library, including all chats and reading states.

Choose your filters in Reading list before exporting Markdown. Switching tabs keeps those filters.

To move browsers, install LinkVault there and import your JSON backup in Collect. No account is needed. Uninstalling the extension or clearing its data can erase your library. Keep backups safe: they include captured message context.

From a conversation

This dashboard controls the LinkedIn tab where you clicked the extension icon. Open a conversation there before starting.

Both live modes read LinkedIn’s page. LinkedIn prohibits scraping extensions and automation, so account restrictions are possible. Automatic scrolling does not make collection compliant. Read LinkedIn’s policy.

Diagnostics contain layout measurements and scrolling progress, not message text or link URLs.

Automatic mode pauses after 30 seconds without new messages or 10 minutes. It cannot certify that the entire history was loaded.

From a saved file

Import a saved chat HTML page, a text link list, or a LinkVault JSON backup. This mode does not interact with LinkedIn.

HTML imports include only messages present in the saved page. If message markup is unavailable, LinkVault extracts candidate links for you to review.

A small guide to LinkVault

A local library for links shared with you. No account, no cloud service.

  1. Collect or import

    Choose Collect. Import a saved HTML page, TXT link list, or LinkVault JSON backup. For live capture, first open one chat in the full LinkedIn messaging page, then click the extension icon from that tab. Give the chat a name if you want.

  2. Choose manual or automatic

    Read the risk notice before enabling live capture. Manual watches messages as you scroll. Automatic loads older messages. Both can violate LinkedIn rules and risk account restrictions. Press Start only if you accept that risk. The in-page indicator shows elapsed time and saved links; Stop ends the session. No completeness guarantee is made.

  3. Organize your reading list

    Return to Reading list. All chats deduplicates shared URLs. Filter by chat, topic, site, or reading state. Use Edit title & topic to correct suggestions or enter any custom topic. Click an article title to open its original page.

  4. Mark what you read

    A new link is unchecked. Check it only after reading. Use Reading for unfinished links and Archived to put one aside. Opening a link does not mark it Read. Delete removes it from all chats; Undo last deletion is available in this dashboard.

  5. Review your reports

    Reports shows saved, To read, Reading, Read, and Archived counts, with chat and topic breakdowns. It is a snapshot of current states, not a dated reading history.

  6. Export and protect your library

    Choose your filters in Reading list, then open Export & backup. Markdown exports every filtered page for Obsidian. JSON backs up the entire library, including private context. Import that JSON in Collect on another compatible browser or device. Keep backups before uninstalling or clearing browser data.

If capture fails, refresh LinkedIn and reopen LinkVault from the conversation tab. Show scrolling diagnostics in Collect gives layout measurements without message text or URLs. Supported files: HTML, TXT, and LinkVault JSON, not LinkedIn archive ZIP/CSV.
