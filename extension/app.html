A small guide to LinkVault

A local library for links shared with you. No account, no cloud service.

  1. Add or restore links

    Use Collect for HTML/TXT files or live LinkedIn capture. Use Backup & restore for JSON or Markdown. For live capture, open one full LinkedIn conversation and click the extension icon while that tab is active. Give the chat a name if you want.

  2. Choose manual or automatic

    Read the risk notice before enabling live capture. Manual watches messages as you scroll. Automatic loads older messages. Both can violate LinkedIn rules and risk account restrictions. Press Start only if you accept that risk. The in-page indicator shows elapsed time and saved links; Stop ends the session. No completeness guarantee is made.

  3. Organize your reading list

    Return to Reading list. All chats deduplicates shared URLs. Filter by chat, topic, site, or reading state. Add custom topics in the Topics panel, then use Edit title & topic to assign one. Click an article title to open its original page.

  4. Mark what you read

    A new link is unchecked. Check it only after reading. Use Reading for unfinished links and Archived to put one aside. Opening a link does not mark it Read. Delete removes it from all chats; Undo last deletion is available in this dashboard.

  5. Review your reports

    Reports shows saved, To read, Reading, Read, and Archived counts, with chat and topic breakdowns. It is a snapshot of current states, not a dated reading history.

  6. Back up, restore, or start fresh

    Backup & restore downloads filtered Markdown or a full JSON backup. Import JSON there to keep reading states, chats, and custom topics on another browser. Markdown brings back links and topics, but new links start To read. Delete all links requires confirmation and has no Undo, so download JSON first. Chat names and preferences stay.

If capture fails, refresh LinkedIn and click LinkVault's toolbar icon from the full conversation tab. Show scrolling diagnostics in Collect gives layout measurements without message text or URLs. Supported files: HTML, TXT, Markdown, and LinkVault JSON, not LinkedIn archive ZIP/CSV.

Delete all links?

Chat names and preferences stay. Links, context, and deletion exclusions are removed. There is no Undo for this action, but you can import a saved backup.

Delete this chat?

Links that also belong to another chat stay in your library. Links and captured context unique to this chat are removed. There is no Undo.

Delete this topic?

Links stay in your library and move to Unsorted. There is no Undo.
