# Security reports

Do not post private conversations, credentials, or usable exploit details in public issues.

Once the repository exists, use GitHub private vulnerability reporting if enabled. Until then, contact Ahmed through his [LinkedIn profile](https://www.linkedin.com/in/ahmedhossamdev/) to arrange a private report. Send a short description first, not private chat data. No response-time guarantee is made.

Include extension and browser versions, impact, a synthetic reproduction, and any proposed mitigation. Redact personal information and tokens.

This pre-release has not received an independent security audit. Browser-store approval or a security fix would not remove the separate account risk of live LinkedIn collection.
